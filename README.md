# เมฆา (Mekha Weather) — พยากรณ์อากาศส่วนตัว · MixImage

แอปพลิเคชันพยากรณ์อากาศส่วนตัวแบบเรียลไทม์ พร้อมบทวิเคราะห์สภาพอากาศเชิงลึกภาษาไทย คุณภาพอากาศ (PM2.5 & UV) และระบบประเมินความเสี่ยงน้ำท่วมล้นตลิ่งจากโมเดลอุทกวิทยาโลก (GloFAS v4)

## ✨ ฟีเจอร์หลัก
- **สภาพอากาศเรียลไทม์ (อัปเดตทุก 15 นาที):** อุณหภูมิจริง, อุณหภูมิความรู้สึกจริง, ความชื้นสัมพัทธ์, ความเร็วและทิศทางลม (พร้อมลมกระโชก), ดัชนีรังสียูวี, ทัศนวิสัย และความกดอากาศระดับน้ำทะเล
- **บทสรุปและคำแนะนำประจำวันอัจฉริยะ:** วิเคราะห์ช่วงเวลาที่มีแนวโน้มฝนตกใน 12 ชั่วโมงข้างหน้า พร้อมคำแนะนำการเดินทางและสุขภาพ
- **พยากรณ์รายชั่วโมง (24 ชั่วโมง) และล่วงหน้า 7 วัน:** กราฟเส้นโค้งพร้อมรายละเอียดสภาพอากาศ โอกาสเกิดฝน และปริมาณน้ำฝนสะสม (มม.)
- **คุณภาพอากาศ (PM2.5):** แถบระดับสีและคำแนะนำสุขภาพตามเกณฑ์มาตรฐานประเทศไทย
- **ประเมินความเสี่ยงน้ำท่วมล้นตลิ่ง (GloFAS v4):** วิเคราะห์อัตราการไหลของน้ำในแม่น้ำ (`m³/s`) เทียบกับสถิติรายเดือนย้อนหลังกว่า 20 ปี (ตั้งแต่ปี 2004)
- **รองรับการค้นหาสถานที่ทั่วไทย:** รองรับทั้ง Google Geocoding API (เมื่อใส่คีย์) และระบบค้นหาสำรองอัตโนมัติจาก Open-Meteo / BigDataCloud โดยไม่ต้องตั้งค่าใด ๆ
